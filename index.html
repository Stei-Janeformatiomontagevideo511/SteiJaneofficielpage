Crée une application web moderne et professionnelle appelée : "STEI MEDIA ASSISTANT" L'application doit être une plateforme complète de gestion de médias et d'assistance virtuelle pour une Page Facebook. OBJECTIF PRINCIPAL : Créer un système permettant de : 1. Stocker et organiser des fichiers Audio 2. Stocker et organiser des fichiers Vidéo 3. Gérer les contenus multimédias 4. Connecter une Page Facebook via l'API officielle Meta/Facebook 5. Recevoir et gérer les messages des clients provenant de Facebook Messenger 6. Créer une assistance virtuelle intelligente capable de répondre automatiquement aux clients 7. Recevoir et gérer les commandes envoyées depuis la Page Facebook 8. Centraliser toutes les conversations et commandes dans un seul tableau de bord. ================================================== DESIGN ================================================== Créer un design moderne, premium et futuriste. Style : - Afro Digital - Moderne - Professionnel - Interface sombre élégante - Effets glassmorphism - Animations fluides - Responsive Mobile, Tablette et Desktop Couleurs principales : - Noir - Violet - Bleu électrique - Orange Afro - Blanc Le design doit être particulièrement optimisé pour les smartphones Android. ================================================== PAGE D'ACCUEIL / DASHBOARD ================================================== Créer un Dashboard avec : - Nombre total de messages Facebook - Messages non lus - Nombre de commandes - Commandes en attente - Nombre de fichiers Audio - Nombre de fichiers Vidéo - Activité récente Ajouter des graphiques modernes pour afficher : - Messages reçus - Commandes reçues - Activité quotidienne - Clients récents ================================================== MODULE AUDIO ================================================== Créer une section appelée : 🎵 AUDIO LIBRARY Fonctionnalités : - Upload Audio - MP3 - WAV - M4A - Lecteur Audio intégré - Play / Pause - Barre de progression - Volume - Télécharger - Supprimer - Modifier le titre - Ajouter une description - Ajouter une image de couverture Organisation avec : - Dossiers - Catégories - Recherche - Tri ================================================== MODULE VIDEO ================================================== Créer une section appelée : 🎬 VIDEO LIBRARY Fonctionnalités : - Upload vidéo - MP4 - MOV - WebM - Lecteur vidéo intégré - Aperçu vidéo - Image miniature automatique - Télécharger - Supprimer - Modifier les informations Organisation : - Catégories - Dossiers - Recherche - Tri ================================================== FACEBOOK PAGE CONNECTION ================================================== Créer une section : 🔵 FACEBOOK PAGE CONNECT IMPORTANT : Utiliser uniquement les API officielles Meta / Facebook. Permettre à l'utilisateur de : - Se connecter avec Facebook Login - Voir ses Pages Facebook autorisées - Sélectionner une Page - Connecter la Page à l'application - Afficher le statut de connexion Créer une page de configuration contenant : - Facebook App ID - Webhook URL - Access Token sécurisé - Page ID Ne jamais afficher publiquement les tokens secrets. ================================================== FACEBOOK MESSENGER INBOX ================================================== Créer une section : 💬 FACEBOOK INBOX Fonctionnalités : - Recevoir les messages provenant de Messenger - Liste des conversations - Afficher le nom du client - Photo du client si autorisée par l'API - Date et heure - Messages non lus - Recherche de conversations Permettre de répondre directement depuis le Dashboard si l'API officielle le permet. Ajouter : - Réponses rapides - Messages enregistrés - Tags clients Exemples de tags : 🔥 Client important 🛒 Commande 💰 Paiement ❓ Question ⏳ En attente ================================================== ASSISTANCE VIRTUELLE ================================================== Créer une section : 🤖 AI VIRTUAL ASSISTANT L'assistant doit pouvoir : - Répondre automatiquement aux clients - Saluer les nouveaux clients - Répondre aux questions fréquentes - Donner des informations sur les produits/services - Guider le client pour passer une commande - Demander les informations nécessaires pour une commande - Transférer la conversation à un humain lorsque nécessaire Créer un système de règles personnalisables. Exemple : CLIENT : "Bonjour" ASSISTANT : "Bonjour 👋 Bienvenue ! Comment pouvons-nous vous aider aujourd'hui ?" CLIENT : "Je veux commander" ASSISTANT : "Excellent 🛒 ! Pouvez-vous nous indiquer le produit ou service que vous souhaitez commander ?" ================================================== GESTION DES COMMANDES ================================================== Créer une section : 🛒 ORDERS / COMMANDES Lorsqu'un client passe une commande via Facebook Messenger, créer automatiquement une fiche commande. Informations : - Numéro de commande - Nom du client - Produit / Service - Quantité - Prix - Statut - Date - Conversation Facebook associée Statuts : 🟡 Nouvelle commande 🔵 En traitement 🟠 En attente 🟢 Terminée 🔴 Annulée Ajouter des boutons : - Modifier - Confirmer - Annuler - Contacter le client ================================================== AI ORDER ASSISTANT ================================================== Créer un système intelligent capable de détecter les intentions : - Commander - Demander un prix - Demander un produit - Demander une information - Demander de l'aide Lorsque l'intention est : "COMMANDE" L'assistant doit lancer automatiquement un processus de commande. Étapes : 1. Demander le produit 2. Demander la quantité 3. Confirmer les informations 4. Créer la commande 5. Informer le propriétaire du site ================================================== NOTIFICATIONS ================================================== Créer un système de notifications. Notifications pour : 🔔 Nouveau message Facebook 🛒 Nouvelle commande 💰 Paiement reçu ⚠️ Client nécessitant une assistance ================================================== ADMIN PANEL ================================================== Créer un panneau Administrateur sécurisé. Sections : - Dashboard - Audio Library - Video Library - Facebook Inbox - Virtual Assistant - Commandes - Clients - Paramètres ================================================== CLIENT DATABASE ================================================== Créer une base de données clients. Informations : - Nom - Facebook User ID si disponible légalement via l'API - Historique des conversations - Historique des commandes - Tags - Notes internes ================================================== TECHNOLOGIES ================================================== Utiliser une architecture moderne. Frontend : - React - Next.js ou React moderne - Tailwind CSS Backend : - Node.js - API REST sécurisée Database : - PostgreSQL ou Supabase Storage : - Supabase Storage ou Cloud Storage sécurisé Authentification : - Auth sécurisée - Admin login ================================================== SÉCURITÉ ================================================== IMPORTANT : - Ne jamais exposer les Access Tokens Facebook - Utiliser des variables d'environnement - Utiliser HTTPS - Sécuriser les API - Vérifier les Webhooks Meta - Respecter les permissions et politiques officielles de Meta ================================================== RESPONSIVE DESIGN ================================================== L'application doit fonctionner parfaitement sur : 📱 Android 📱 iPhone 💻 Ordinateur 📱 Tablette Créer une navigation mobile avec : 🏠 Dashboard 🎵 Audio 🎬 Vidéo 💬 Messages 🛒 Commandes 🤖 Assistant ⚙️ Settings ================================================== NOM DE L'APPLICATION ================================================== Nom : STEI MEDIA ASSISTANT Slogan : "Votre Média, Votre Business, Votre Assistant Intelligent."
